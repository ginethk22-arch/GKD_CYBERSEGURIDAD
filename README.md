
# 🛡️ GKD CyberSeguridad

**GKD CyberSeguridad** es una plataforma web diseñada para ofrecer servicios de seguridad informática de forma moderna, clara y accesible.  
Incluye secciones informativas, formulario de asesoría, inicio de sesión y un panel CRUD simulado para la administración de contenido.

## 🚀 Características principales

- **Página principal moderna** con navegación clara y diseño responsivo.  
- **Servicios de ciberseguridad** con opción para solicitar asesoría personalizada.  
- **Sistema de inicio de sesión simulado** (usuario: `admin@gkd.com`, contraseña: `12345`).  
- **Panel CRUD** para la gestión básica de información:  
  - Editar la barra de navegación.  
  - Agregar o eliminar contactos.  
  - Modificar el banner principal.  
  - Añadir nuevas razones en la sección “Por qué elegirnos”.  
- **Diseño adaptable con Bootstrap 5** y estilos personalizados en CSS.

##  Instalación y uso

1. Clona o descarga el repositorio:
   ```bash
   git clone https://github.com/tuusuario/GKD_CYBERSEGURIDAD.git
   ```

2. Abre el proyecto con tu editor (por ejemplo, Visual Studio Code).

3. Ejecuta el sitio localmente con la extensión **Live Server** o abre `index.html` directamente en el navegador.

4. Accede al panel administrativo:
   - Navega a `iniciasesion.html`
   - Ingresa las credenciales mencionadas arriba.
